ℹ️ À propos de Foyer+

Version prototype 1.0

Foyer+ est une première version autonome : les données sont conservées dans le stockage local du navigateur sur cet appareil. Il n’y a ni compte partagé, ni synchronisation entre téléphones, ni OCR de tickets, ni service d’IA connecté dans cette version. Ces fonctions nécessitent une configuration supplémentaire. Aucun abonnement ni API payante n’est requis pour utiliser ce prototype.
